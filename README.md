# PING! — Secure P2P Messenger 🟢

**PING!** — это легковесный и защищенный peer-to-peer (P2P) мессенджер, написанный на Python. Проект предлагает современный графический интерфейс и обеспечивает максимальную конфиденциальность переписки с помощью надежного сквозного шифрования (E2EE).

## 🌟 Особенности проекта

* **P2P Архитектура:** Прямое соединение между компьютерами без использования централизованных серверов.
* **Сквозное шифрование (E2EE):** Безопасный обмен ключами по протоколу на эллиптических кривых (ECDH) и шифрование самих сообщений алгоритмом AES-256 (через модуль Fernet). Перехватить переписку невозможно.
* **Безопасная локальная авторизация:** Пароли пользователей хешируются с помощью **PBKDF2-HMAC-SHA256** (100 000 итераций) и безопасно хранятся в конфигурационном файле `user_data.json`.
* **Современный UI:** Темная тема и отзывчивый графический интерфейс, построенный на базе `customtkinter`.

## 🛠 Требования и установка

Для работы мессенджера требуется **Python 3.8+**. 

Откройте терминал в папке с проектом и установите необходимые библиотеки:

```bash
pip install customtkinter cryptography plyer pillow

# plyer — системные уведомления (работает на Windows/macOS/Linux)
# pillow (PIL) — работа с изображениями (отображение, масштабирование, сохранение)
```

Готово! Теперь запустите мессенджер:

```bash
python ping.py
```

## 🚀 Как пользоваться

### Регистрация / Вход
1. При первом запуске выберите **РЕГИСТРАЦИЯ**, придумайте имя пользователя и пароль.
2. При последующих запусках используйте **ВОЙТИ** — учётные данные сохраняются в `user_data.json`.

### Создание чата (сервер)
Нажмите **Создать чат** — мессенджер автоматически:
- Найдёт свободный порт начиная с `55555`.
- Определит локальные IP-адреса и публичный IP.
- Отобразит их в чате для отправки другу.

### Подключение к чату (клиент)
Нажмите **Подключиться**, введите IP-адрес друга и порт. Для связи в одной локальной сети используйте локальный IP. Для соединения через интернет — публичный IP друга + проброс порта на роутере.

### Функции чата
| Действие | Как |
|---|---|
| Отправить текст | Введите сообщение и нажмите **ОТПРАВИТЬ** или `Enter` |
| Перенос строки | `Shift + Enter` или `Ctrl + Enter` |
| Добавить эмодзи | Нажмите кнопку 😊 — откроется палитра |
| Отправить изображение | Нажмите 📎 — выберите файл |
| Вставить из буфера | `Ctrl + V` — вставит скриншот или скопированное изображение |
| Увеличить/уменьшить изображение | Двойной клик по изображению откроет просмотрщик |

### Игры
Напишите в чате `крестики` / `tic tac toe` / `ttt` — отправится приглашение.
Соперник получит кнопку **Принять**. Победитель определяется по классическим правилам.

### Безопасность 🔒
- **E2EE**: каждое соединение использует уникальную пару ключей ECDH (SECP384R1).
- **Шифрование сообщений**: AES-256 через `Fernet` (HKDF-вывод ключа из ECDH-секрета).
- **Хранение пароля**: PBKDF2-HMAC-SHA256, 100 000 итераций + уникальная соль.
